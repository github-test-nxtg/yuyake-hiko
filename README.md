# 夕焼け飛行

夕暮れの空を紙ひこうきで飛ぶ、ブラウザで遊べる横スクロールシューティングゲームです。

## 遊び方

- 矢印キー / WASD で移動(スマホは画面をドラッグ)
- 弾は自動で発射
- P キーで一時停止
- 敵を1機でも左端まで通すとライフが減る
- 赤い「P」を取ると弾が最大4段階まで強くなる
- 約40秒ごとにボス「大凧」が登場

## 起動方法

`index.html` をブラウザで開くだけで遊べます。インストールやビルドは不要です。

## ファイル構成

- `index.html` … ゲーム本体(HTML / CSS / JavaScript を1ファイルに収録)
